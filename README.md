# 今天课程

轻量的课程表 App，使用 Flutter / Dart、Riverpod、Drift / SQLite，以及 Kotlin / Swift 原生通知。

## 三个主页面

- **日程**：查看任意一天的课程与一次性日程，突出下一项安排，支持折叠已结束的安排。
- **课表**：整周时间网格，左右滑动切换前后周，展示真实上课日期及教室。重叠课程并排显示，点击可查看和编辑。
- **我的**：课表设置、导入课表、全部课程、提醒设置和学期起始日期。数据保存在本机，无需登录。

底部采用透明悬浮玻璃 Dock：透出后方内容并做背景模糊、边缘高光和玻璃选中透镜。可点击页面按钮，也可在 Dock 上横向拖动，透镜跟手移动，松手吸附并切换页面；取消拖动会回到原选项。支持大字体、高对比度与减少动态效果设置。课表右上角只有一个可展开/收起的工具按钮，集中提供添加课程、导入课表和课表设置。添加、编辑、导入为独立路由页。

## 手势与周次导航

- 在课表内容区域左滑进入下一周，右滑返回上一周，日期和课程一起更新。顶部箭头及“本周”按钮与滑动使用同一分页状态。
- 竖向滑动继续浏览当天的节次，回到已浏览的周会保留其竖向滚动位置。
- 点击课程仍进入编辑，点击空白格仍可排课；横向滑动不会误触编辑。
- 在底部 Dock 上拖动切换主页面，与课表切周手势分开处理；切到其他页面再返回时保留所查看的周。

## 手动排课与课表设置

从“课表 → 右上角工具 → 课表设置”或“我的 → 课表设置”进入：

- 每天 1–24 节、第一节上课时间、每节时长、普通课间。
- 午休和晚休分别设置在第几节后及持续时间；0 为不设置。
- 批量模板修改后即时生成时间表，每一节的上课/下课时间也可单独微调。
- 每周任意一天作为起始日，从起始日起连续显示 5 或 7 天；教学周同步按所选起始日计算。
- 按节次显示或切换成小时刻度。课表高度可在 60%–160% 调节，带紧凑/标准/舒展预设；显示密度不改变课程时间。导入课程超出配置时段时会扩展显示范围。

点击课表空白格可直接为该星期、该节添加课程，也可从工具栏添加。手动课程支持“按节次”选择连续起止节次，或切换“自定义时间”。按节次课程保存绑定，之后修改上课时间表会在同一数据库事务中更新课程时间，并同步原生通知调度。导入课程、一次性日程和自定义时间课程使用各自时间。

时间重叠、跨午夜、午休/晚休冲突会显示错误；每天节数减少到不足以容纳已有绑定课程时，保存会说明需调整哪门课，原设置和课程不会被部分修改。旧版手动课程保留原时间，可在编辑页切换为按节次。

## 导入 .ics 课表

在“我的 → 导入课表”或“课表 → 右上角工具 → 导入课表”选择手机上的 `.ics` 文件，先预览，再确认追加导入。可选择保留文件内的提醒，例如提前 20 分钟。是否启用文件时间可在“我的 → 提醒设置 → 沿用文件课前提醒”切换；未指定时使用全局设置。相同课程内容再次导入会跳过，不覆盖手动课程。

导入保留实际日期、上课时刻、地点、备注、时区、重复结束日期和排除日期，避免将有限教学周误变为无限每周重复。支持：

- 单次 VEVENT，明确的 DTEND。
- UTC、浮动本地时间及 timezone 数据库识别的 TZID（包括 Asia/Shanghai）。
- 有 COUNT / UNTIL 的 DAILY、WEEKLY、INTERVAL、BYDAY、WKST。
- EXDATE、RDATE、折行文本及标准文本转义。
- 负数的 START-related 小时/分钟 VALARM。

单文件最大 2 MB、500 组课程、合计 5000 次上课，重复范围不超过 5 年。全天、跨午夜、无限重复、MONTHLY、RECURRENCE-ID 单次改期等不支持的条目会明确列出，用户确认后仅导入可支持部分。导入的课程组可修改名称、地点、备注、颜色；日期/时刻变化时需删除对应组后重新导入。

已用用户提供的 WakeUp 文件本地验证：38 组时段、12 门课程、199 次上课、所有提前 20 分钟提醒完整识别。该个人文件不包含在源码和 APK 中；测试夹具使用独立的示例数据。

## 提醒与安装

Android 16+ 使用公开 Live Updates 通知协议，沿用已在 OPPO / ColorOS 上岛成功的方式。课前倒计时 → 正在上课 → 下课前切换“快下课”和系统倒计时 → 下课自动撤下；一次性日程使用“开始 / 进行中 / 结束”文案。旧 Android 系统使用普通持续通知。

在“我的 → 提醒设置”分别设置上课前多久提醒，以及 Android 下课前多久显示流体云。两项默认均为 10 分钟，可选常用时间或自填 **1–1440 分钟**，保存后立即重新调度，重启后保留。下课提前量超过课程长度时，从上课开始显示下课提示；不会在上课前误报下课。日程仅使用开始前提醒。

沿用文件课前提醒默认开启以保持旧版行为；修改上课前时间会自动关闭此选项，让所有课程和日程统一使用新设置。可重新开启以恢复导入文件时间，原始提醒数据不会被删除。下课前设置始终独立于文件的课前提醒。预览使用当前下课提前量，倒计时归零或最多 5 分钟后结束。

Android 使用 AlarmManager 调度，原生存储保存完整日期，重启、应用更新、时间或时区变更后恢复。关闭提醒或删除课程会撤销对应通知和未来调度。当前项可手动结束，不再重发同一次提醒。下课提示单独安排唤醒边界，课前分钟刷新使用不唤醒手机的普通 RTC，减少对省电配额的消耗。同一次课程的下课提示只触发一次；提醒设置面板提供下课提示预览。系统省电仍可能延后后台更新；准时提醒需在系统开启 exact alarm 权限。强制停止后请重新打开 App。

iOS 15+ 使用普通本地通知，优先安排最近 60 次提醒，并在重新打开/回到应用时续排；未接入 ActivityKit。iOS 原生代码需要 macOS / Xcode 编译和真机验证，Linux 云环境尚未验证。

从 Releases 的下载链接获取 ARM64 APK。v0.7.0 与之前版本保持包名 `com.kitty191.schedule` 和同一开发签名，可直接覆盖安装。SQLite 从旧版升到 v4，会保留已有课程、导入日期、课表高度、学期和提醒设置，新增下课提前量默认 10 分钟。当前签名用于测试，尚未配置商店发布签名。

真机步骤：安装 → 我的 → 导入课表 → 选择 `.ics` → 核对预览 → 确认导入 → 课表查看对应周。再到“我的 → 提醒设置”主动开启通知、顶部提醒和准时提醒权限，可通过“发送课程预览”立即检查上岛。

cd android
./gradlew :app:testDebugUnitTest :app:lintRelease
