# 1.0.2 流体云进度提醒

新版继续沿用真机已验证的包名、通知渠道和公开 Android Live Updates 接口，将原先的纯文字提醒改为系统进度卡片。

## 显示内容

课前示例（这是内容示意，实际排版由手机系统决定）：

```text
课前 · 第 3–4 节 · 第 8 周             系统倒计时
08:30 上课  ·  10:05 下课
大学英语 · 东校区综合楼 B402
灰色课前段 ━━ 开课节点 ━━ 紫色上课段
```

- 进度覆盖“开始提醒 → 上课 → 下课”，两段长度按真实持续时间计算，书本图标跟随进度移动。
- 顶部收起时使用简短的“5分上课 / 上课中 / 10分下课”；展开后提供上下课时刻、课程、教室、状态和系统倒计时。较长提前量使用小时文案，避免挤满顶部胶囊。
- “快下课”按用户设置的下课提前量切换，下课撤下提醒。一次性日程使用“开始 / 进行中 / 结束”，不显示课程节次或下课状态。
- 节次来自手动绑定，或与课表设置完全匹配的起止时间。自定义时间不匹配、实际本地时刻因时区变化不再匹配时省略节次。教学周使用学期日期及每周起始日计算，未设置或学期尚未开始时省略。
- 修改每周起始日会立即同步提醒的教学周；仅修改课表显示高度不会重新调度。清除学期日期也会正确清除数据库旧值。

## 与参考图的区别

参考图是 iOS 的自定义实时活动。Android 的公开上岛接口使用系统模板，不能指定同样的黑底、卡片圆角、左右文字位置和独立教室胶囊。新版提供紫色进度、开课节点与跟随图标，文字颜色由系统处理以兼容浅色、深色和厂商主题。ColorOS 是否展示所有字段、如何排列和使用颜色，需在 OPPO 真机上确认。

不使用悬浮窗或自定义 RemoteViews 替代流体云。自定义通知布局会失去公开 Live Updates 的提升资格。Android 16 首发实现与后续系统的 colorized 判定不同：优先按当前公开文档构建，再通过 `hasPromotableCharacteristics()` 检查；仅在系统要求旧规则且检查通过时使用旧规则。保留原渠道 ID 及用户通知权限设置。

Android 24–35 保留普通持续通知，展开提供完整文字和普通进度条。iOS 仍使用普通本地通知，本次没有加入 ActivityKit。

## 真机查看

1. 安装 [1.0.2 ARM64 APK](https://github.com/kitty191/schedule/raw/refs/heads/builds/android-v1.0.2/downloads/today-courses-v1.0.2-arm64.apk)，可覆盖原版 1.0.1，保留课程和设置。
2. 打开“我的 → 提醒设置”，检查通知和顶部实时提醒权限。
3. 点“发送课程预览”，返回桌面并展开顶部提醒；再用下课预览检查“快下课”和结束倒计时。
4. 检查真实课程在所设的课前、下课前边界切换，并在下课时撤下。

预览保留所选课程的名称、地点和节次，使用模拟时刻，明确标注“预览”。时间和进度不会在每次刷新时重新起算。倒计时归零或最多 5 分钟后结束；预览不修改课表。长下课提前量仍会显示下课阶段，跨日预览注明“次日”。升级时尚未结束的旧版预览会转换为新时间格式。

进度每分钟通过不唤醒手机的 RTC 刷新，倒计时由系统绘制；课前及下课前等提醒边界仍用原有的 AlarmManager 唤醒调度。休眠及省电策略可能延后进度刷新，不会为进度增加每分钟唤醒。用户结束或划掉的提醒会记入当前课程的关闭状态，避免进度刷新将它重新贴回。

- Flutter 静态分析无问题，79 项交互/数据测试通过。
- 45 项 Kotlin / Robolectric 测试通过，覆盖日程规划、连续进度、提醒边界、零提前量、文件提醒、节次和教学周、时区及夏令时、模拟预览测试。

- ARM64 release 构建、Android lint、包名/版本/原开发签名及 APK 对齐检查。

这些检查不能代替 OPPO 的流体云、权限弹窗和省电行为真机验证。
