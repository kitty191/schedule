# 1.0.0 整体审查

审查覆盖 Flutter 界面与导航、触摸手势、SQLite 数据操作和升级、.ics 导入、Android 实时提醒、平台项目和构建文件。源码与安装包均以 `Codex <codex@openai.com>` 提交，源码进入独立 PR 等待审核。

## 本次修复

| 问题 | 修复后的行为 |
| --- | --- |
| 在夜课扩展范围、课间或小时模式点击空白格时，错误地选择模板中的节次 | 按点击时刻创建自定义时间课程；正常节次内部继续绑定节次 |
| 三门以上重叠课程会被挤成无法阅读的细条，数量多时还会出现负宽度 | 两门继续并排；更多重叠项用数量卡片显示，点击可逐门编辑、删除，并即时更新课表 |
| 同一天有多个 RDATE 上课时刻时，日程和课表只显示第一次 | 新导入的数据按时刻拆组，保留所有上课时间、提醒和去重能力 |
| 文件读取失败保留旧预览；取消文件选择清除了成功导入状态 | 失败清空旧预览，取消保留原状态，防止误导入和重复确认 |
| 恢复到前台的同步与保存同时进行时，旧快照可能覆盖新状态 | 数据写入、读取快照及原生同步串行执行，失败不会阻断后续操作 |
| 依次结束两个重叠提醒后，第一个提醒可能再次出现 | 记录尚未失效的多个已结束项，兼容旧版单个记录 |
| 数据读取失败时，其他标签仍可打开依赖数据的编辑页 | 所有主页面共用加载/失败状态，可重试恢复 |
| 窄屏大字体下部分选择器标题挤压按钮，历史学期日期超出固定年份范围会断言失败 | 标题居中换行，日期范围包含已保存日期 |
| 横屏展开工具占用过多高度，Dock 会遮挡星期日期 | 矮横屏合并标题与周次导航、展开工具内联显示，并使用紧凑 Dock，并为 Dock 预留空间，日期与网格不被遮挡 |
| 全部课程页把有限日期的导入课误标为每周重复 | 明确区分按星期与按导入日期上课 |
| 起止在同一分钟内的文件条目预览通过，却导致整个导入事务失败 | 在解析时给出该条目不支持的说明，其他有效条目可以继续导入 |

保留已有的 60% / 80% 显示、晚课高度及左侧时间刻度对齐修复。展开工具尊重减少动态效果设置，颜色选择补充读屏标签；保存课程时收起键盘。

## 版本、安装与仓库

版本为 1.0.0（versionCode 10），包名仍是 `com.kitty191.schedule`。SQLite 保持 schema 4，升级时保留现有课程、导入日期、课表和提醒设置；本次无需重建数据库。

安装包签名保持与 0.7.x 相同，可覆盖安装。签名用于当前开发分发，未切换为商店发布签名；私钥、个人课表、本地 SDK 路径和缓存不提交。

Gradle Wrapper、校验文件、依赖锁定文件、Drift 生成文件、Android / iOS 项目、测试及 CI 工作流均在版本控制内。源码目录移除误合并进入的旧 APK / 预览图，只保留下载说明；历史下载分支仍保留旧版本。1.0.0 安装包放在独立下载分支，避免二进制包混入源码 PR。

## 验证边界

云环境没有已授权的 Android 真机或模拟器，也没有 macOS / Xcode。本次未执行 OPPO 上的系统权限弹窗、熄屏/重启/省电策略、流体云实际展现和 iOS 原生编译。Android 公共通知接入沿用用户已成功实测的方式；iOS 继续使用普通课前通知，最近 60 次通知需定期打开应用续排。自动化检查及渲染图不能替代这些系统行为的真机确认。
