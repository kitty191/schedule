版本 1.0.4（15），应用名“今天课程”，正式包名 `com.kitty191.schedule`。可直接覆盖原版 1.0.0 / 1.0.1 / 1.0.2 / 1.0.3，保留原版课程和设置。

本版本修复下课前没有提醒的问题：课前或课中云收起后，下课提示仍独立触发；到期以“下课前提示”分类发布一次醒目提示，默认无声音及振动。保留系统自动倒计时。保留紫色进度、上下课时刻、课程教室、节次及教学周；实际流体云排版由手机系统决定。保留课程底部编辑面板及提醒下拉关闭手势。

试验包 `com.kitty191.schedule.sheets` 仍为独立应用；试验数据不会自动迁入正式版。
